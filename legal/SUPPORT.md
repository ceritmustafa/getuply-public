# GetUply Support

Need help with GetUply, want to report an issue, or have a feature request?

Email: **mustafacrit@gmail.com**

When reporting a problem, please include:

- Your iPhone model and iOS version
- Your GetUply version and build number from Settings
- The alarm or wake mission you were using
- The steps that reproduce the problem

Do not send reference photos, QR-code contents, NFC identifiers, or other
sensitive information. GetUply has no user accounts, so support will never ask
for a password.

## Alarm checklist

- Allow Notifications and Alarm access when GetUply asks.
- Keep the iPhone powered on with audible volume.
- Review the alarm-health status shown in GetUply Settings.
- For critical obligations, keep a backup alarm because device power, system
  settings, permissions, and operating-system conditions can affect delivery.

## Purchases

Use **Settings → Restore Purchases** in GetUply to restore an active Pro
subscription. Subscriptions can be managed or cancelled in Apple ID settings.
